# 다국어와 이미지 관리 안내

이 문서는 홈페이지의 **언어 전환**과 **그림·사진**을 원장님·담당자분이
직접 손보실 수 있도록 정리한 것입니다. 프로그램을 몰라도 됩니다.

---

## 1. 지원 언어

| 코드 | 언어 | 상태 |
|------|------|------|
| `ko` | 한국어 | 원본. 모든 내용 |
| `en` | English | 뼈대 전체 번역 완료 |
| `zh` | 简体中文 | 뼈대 전체 번역 완료 |
| `ja` | 日本語 | 뼈대 전체 번역 완료 |
| `ru` | Русский | 뼈대 전체 번역 완료 |

**"뼈대 전체"란** 메뉴 · 푸터 · 홈 화면 전부 · 예약/문의 폼 · 동의 문구 ·
오류 안내 · 진료 분야 이름과 한 줄 소개까지입니다.

**진료 분야 상세 본문 10개도 4개 언어 전부 번역되어 있습니다.**
(줄기세포 · 피부과 · 성형외과 · 비뇨기과 · 에스테틱 ·
내성발톱 · 두피케어 · 림프해독 · 월드투어 · 퀀텀)

**아직 한국어만 있는 것**은 의원소개 · 오시는 길 · 공지 · 갤러리 ·
FAQ · 개인정보처리방침 본문입니다. 이 페이지들은 다른 언어로 보실 때
**"현재 한국어만 제공됩니다"** 안내가 그 언어로 뜨고, 문의하기 버튼이
함께 나옵니다. 번역된 척 두지 않았습니다.

번역이 있는 진료 페이지에는 대신 **"참고용 번역이며 정본은 한국어입니다"**
안내와 한국어 원문 링크가 뜹니다. 두 안내는 성격이 다릅니다.

### 언어는 어떻게 정해지나

1. 주소에 `?lang=en` 처럼 붙어 있으면 그 언어
2. 지난번에 고르신 언어 (그 브라우저에만 기억됩니다)
3. 방문자의 브라우저 설정 언어
4. 위 셋 다 아니면 한국어

머리말 오른쪽 **🌐 버튼**으로 언제든 바꾸실 수 있습니다.

## 2. 번역 문구 고치기

파일 한 개만 보시면 됩니다: **`js/lang.js`**

```js
en: { name: "English", short: "EN", htmlLang: "en", s: {
  "nav.cta": "Book a Visit",        ← 이 따옴표 안의 글자를 고치시면 됩니다
  "footer.privacy": "Privacy Policy",
  ...
```

* 왼쪽(`"nav.cta"`)은 **자리 이름**입니다. 절대 고치지 마십시오.
* 오른쪽 따옴표 안의 글자만 바꾸십시오.
* 어떤 줄을 통째로 지우면 그 자리에 **한국어가 그대로** 나옵니다.
  망가지지 않으니 안심하셔도 됩니다.

## 2-1. 진료 상세 본문 고치기

본문은 분량이 커서 언어팩과 따로 두었습니다.

```
i18n-src/<언어>/<진료키>.json     ← 여기를 고칩니다
        ↓  node tools/build-svc.js
js/svc-<언어>.js                  ← 자동으로 만들어집니다 (직접 고치지 마십시오)
```

예를 들어 영어 줄기세포 페이지를 고치시려면
`i18n-src/en/stemcell.json` 을 열어 고치신 뒤,

```
node tools/build-svc.js
```

한 줄만 실행하시면 됩니다.

**조립기가 세 가지를 검사합니다.** 하나라도 걸리면 멈춥니다.

| 검사 | 왜 |
|------|-----|
| 그룹·항목 수가 한국어와 같은지 | 다르면 메뉴의 바로가기 주소(`#t0-3` 등)가 엉킵니다 |
| 그 언어에 없어야 할 문자가 섞였는지 | 번역하다 한 글자씩 놓치는 일이 실제로 생깁니다 |
| JSON 형식이 맞는지 | 쉼표 하나가 빠지면 그 언어 전체가 안 나옵니다 |

작업 중 이 검사가 실제로 세 건을 잡았습니다.
일본어에 한글 한 글자, 일본어에 러시아어 조각, 러시아어에 한자 한 글자.
사람 눈으로는 놓치기 쉬운 것들입니다.

### 파일 크기

진료 상세 페이지에서만, 그것도 **보고 계신 언어 한 개만** 불러옵니다.
다른 페이지에는 아무 영향이 없습니다.

| 언어 | 원본 | 실제 전송량(gzip) |
|------|------|-------------------|
| 영어 | 165KB | 47KB |
| 중국어 | 143KB | 45KB |
| 일본어 | 188KB | 50KB |
| 러시아어 | 256KB | 60KB |

참고로 모든 페이지에서 늘 불러오는 `js/main.js` 가 gzip 55KB입니다.

> ⚠ **기계번역을 그대로 올리지 마십시오.**
> 의료 문구는 번역 과정에서 쉽게 과장됩니다.
> "도움이 됩니다"가 "치료됩니다"로 바뀌면 의료광고 규정 위반입니다.
> 지금 들어간 번역도 원문보다 세게 표현하지 않는 쪽으로 맞췄습니다.

### 번역에서 특히 신경 쓴 부분

원문의 **한정 표현**을 하나도 빠뜨리지 않고 옮겼습니다. 예를 들어

| 한국어 원문 | 왜 중요한가 |
|---|---|
| "보조 관리이며 표준 치료를 대신하지 않습니다" | 빠지면 그 자체로 과장 광고 |
| "임상시험의 틀 안에서만" (줄기세포·PRP 주입) | 국제 진료지침의 판단을 그대로 전달 |
| "약 3명 중 1명에게 멍이 생깁니다" (35.7%) | 불리한 숫자를 지우면 안 됩니다 |
| "6개월 뒤 시술 전 상태로 돌아갑니다" (레이저 토닝 단독) | 같은 이유 |
| "과잉진단 가능성이 함께 논의됩니다" (PSA 검사) | 같은 이유 |
| "영구히 줄인다는 근거는 확인되지 않습니다" (모공) | 같은 이유 |

번역본을 검수하실 때 **이런 문장이 사라지지 않았는지**부터 확인해 주십시오.

> ⚠ **원장님 성함 표기**
> 중국어·일본어판에서 성함을 한자나 가타카나로 옮기려면
> 원장님께서 실제로 쓰시는 표기를 확인해야 합니다.
> 임의로 추측할 수 없어 지금은 네 언어 모두 로마자
> `Park Jong-yun` 으로 두었습니다. 확인되면 언어팩에서 바꿔 주십시오.

## 3. 그림 (images/motif-*.svg)

홈 화면 배경, 소개 섹션, 진료 페이지 상단 띠에 들어간 무늬입니다.

| 파일 | 뜻 | 쓰이는 곳 |
|------|-----|-----------|
| `motif-cell.svg` | 세포 · 재생 | 홈 소개 섹션, 줄기세포, 진료안내 |
| `motif-light.svg` | 빛 | 홈 첫 화면 배경, 피부과, 에스테틱, 퀀텀, 예약 |
| `motif-flow.svg` | 흐름 · 순환 | 비뇨기과, 림프해독, 오시는 길, 공지, 문의 |
| `motif-leaf.svg` | 성장 | 의원소개, 두피케어, 내성발톱, 월드투어 |
| `motif-form.svg` | 윤곽 | 성형외과, 갤러리, FAQ, 개인정보처리방침 |

**이건 사진이 아니라 도형입니다.** 그래서

* 저작권 문제가 없습니다 (직접 그린 것입니다)
* "우리 병원 시술실"로 오해될 수 없습니다
* 전부 합쳐 70KB 남짓이고, 확대해도 깨지지 않습니다

어느 페이지에 어떤 무늬를 쓸지는 `js/main.js` 의
`MOTIF_BY_PAGE`, `MOTIF_BY_SVC` 목록에서 바꾸실 수 있습니다.

## 4. 실제 병원 사진 넣기

### 갤러리 (`gallery.html`)

지금은 빈 자리 6칸이 있습니다.

```html
<div class="ph"><span class="ic">◻</span>진료실</div>
```

사진이 준비되면 이 한 줄을 통째로 아래처럼 바꾸십시오.

```html
<img src="images/room-01.jpg" alt="명동미래셀의원 진료실">
```

* 사진 파일은 `images/` 폴더에 넣으십시오.
* `alt="..."` 는 눈이 불편하신 분의 화면 낭독기가 읽어 줍니다. 꼭 적어 주십시오.
* 사진을 넣으면 **누르면 크게 보이는 기능이 자동으로 켜집니다.**
  (화살표 ← →, 닫기 Esc 도 됩니다)
* 가로세로 4:3, 긴 변 1600px 정도면 충분합니다.

### 🚫 절대 하지 마셔야 할 것

**무료 스톡 사진이나 AI로 만든 그림을 "우리 병원 진료실·시술실"처럼
올리는 것.** 두 가지 문제가 동시에 생깁니다.

1. **의료광고 규정 위반** — 실제와 다른 시설·장비를 보여 주는 광고는
   의료법상 거짓·과장 광고에 해당할 수 있습니다.
2. **환자분을 속이는 일** — 사진을 보고 오신 분이 실제와 다른 공간을
   마주하게 됩니다. 신뢰가 한 번에 무너집니다.

그래서 갤러리 자리는 **실제 사진이 오기 전까지 비워 두었습니다.**
분위기용 그림은 위의 `motif-*.svg` 로만 쓰고 있습니다.

### 원장님 사진

`images/doctor.jpg` 가 이미 의원소개 페이지에 들어가 있습니다.
바꾸시려면 같은 이름으로 덮어쓰시고, `about.html` 의 `?v=5` 숫자를
`?v=6` 처럼 하나 올리시면 방문자 화면에도 바로 반영됩니다.
