## 1. 전제: "저작권 없는 사진"이 아님

두 사이트 모두 저작권이 없는 것이 아니라 **조건부 무료 사용**이 가능한 이미지입니다.

### 클립아트코리아 무료콘텐츠

| 항목 | 내용 |
|---|---|
| 홍보 홈페이지·배너·팝업 | 사용 가능 |
| 출처 표기 | 불필요 (단, 한국관광공사 제공 이미지는 출처 표기 필수) |
| 사용 기한 | **다운로드 후 30일 이내 사용**. 기한 경과 시 재다운로드 |
| 다운로드 수량 | 하루 5컷 |
| 다운로드 조건 | 로그인 + 마케팅 수신 동의 필요 |
| 사용 불가 | 로고·CI/BI, 앱/서버 임베딩, 제품 디자인 |
| 기록 | 회원 탈퇴 시 무료 콘텐츠 이용 내역 확인 불가 |

### Pixabay

- 상업적 사용 가능, 출처 표기 불필요
- 단, 사진 속 **인물·로고·브랜드·건물** 등은 별도 권리(초상권·상표권 등)가 있을 수 있음
- 제3자 동의 필요 여부 판단 책임은 **전적으로 사용자**에게 있음
- 금지: 식별 가능한 인물을 모욕적·명예훼손적으로 묘사, 제품·서비스를 보증하는 것처럼 암시

## 2. 핵심 규칙: 진료 페이지에 인물 사진 사용 금지

**모든 진료·시술 관련 페이지에는 사람이 나오는 사진을 쓰지 않습니다.**

### 근거

- **클립아트코리아 FAQ:** 병원의 시술·수술 홍보에 "의료뷰티"가 아닌 일반 인물 콘텐츠 사용은 초상권 문제의 주요 사례. before & after가 아니어도 모델이 효과를 보증하는 것처럼 오인될 수 있어 사용 불가. 클립아트코리아는 오용을 모니터링하며 발견 시 교체·사용 중지를 요청함.
- **Pixabay 라이선스:** 식별 가능 인물의 명예훼손적 묘사, 보증 암시 금지.
- **의료법 제56조:** 치료 효과를 암시하는 표현은 위반 소지. 인물 사진이 효과 암시로 읽힐 수 있음.

### 특히 주의 (추정 판단)

- 비뇨기과(발기부전·전립선 등) 페이지에 실제 인물 얼굴을 쓰면 "해당 인물이 그 질환이 있다"는 인상을 줄 수 있어 위험도가 가장 높음.

### 인물 사진이 꼭 필요한 경우

- 클립아트코리아 **"의료뷰티"** 카테고리 인물 콘텐츠만 사용 (모델이 병원 홍보 사용을 허가한 콘텐츠)
- 이 카테고리가 무료콘텐츠에 포함되는지는 **확인되지 않음** (유료 멤버십 전용일 가능성 있음)

## 4. 검색 요령 (클립아트코리아)

| 기능 | 입력 방법 | 예시 |
|---|---|---|
| NOT 검색 (특정 요소 제외) | `검색어 -제외어` | `스파 -여자`, `피부 -사람` |
| AND 검색 (모두 포함) | `검색어1 검색어2` | `세포 녹색` |
| OR 검색 (하나라도 포함) | `검색어1, 검색어2` | `현미경, 실험실` |
| 컬러 검색 | 상세검색 → 컬러피커 또는 색상값 입력 | 홈페이지 메인 초록 색상값 입력 |
| 형태 지정 | 상세검색 → 가로형/세로형/정사각형 | 히어로 배너는 가로형 |
