# 병원 확인 사항

홈페이지를 만들면서 **제가 임의로 정하거나 추정한 것**, 그리고 **병원에서만 알 수 있는 것**을 모았습니다.
확인되는 대로 하나씩 지워 나가시면 됩니다.

> 작성 기준일: 2026-09-17
> 확인이 끝난 항목은 `- [x]` 로 바꾸고, 확정값을 옆에 적어 주십시오.

## ① 지금 홈페이지에 **틀린 값이 올라가 있을 수 있는** 것

여기 있는 것들은 확인 전까지 **사실이 아닐 수 있는 상태로 공개되어 있습니다.** 가장 먼저 봐 주십시오.

### - [ ] 1. 병원 주소

현재 표기: **서울특별시 중구 퇴계로 123, 7층**

제가 실제 주소를 받은 적이 없습니다. `퇴계로 123` 은 형태상 예시 주소로 보이는데,
진짜 주소인지 확인이 안 됩니다. **실제 주소가 다르면 환자분이 엉뚱한 곳으로 갑니다.**

나오는 곳: 홈 · 오시는 길 · 문의하기 · 푸터 전체 · 영어/중국어/일본어/러시아어판

현재 표기: **박종윤 / 대표원장** — 제가 제안한 값입니다.

법정 고지 항목이라 실제 지정된 분과 달라선 안 됩니다.
보호책임자를 원장님이 아닌 분으로 지정하실 수도 있습니다.

나오는 곳: `privacy.html` (개인정보처리방침)

실제로 방침을 시행하기로 한 날짜여야 합니다.

## ② 의료광고 규정 — **반드시 원장님이 보셔야 하는** 것

### - [ ] 5. 홈 문구 "줄기세포의 거장"

현재 홈 첫 화면에 이렇게 적혀 있습니다.

> 세포의 시간에서 새롭게 재생되는 당신 본연의 건강과 아름다움.
> **줄기세포의 거장이** 제안하는 비뇨의학·성형·피부 프리미엄 케어,
> 명동미래셀의원입니다.

"거장" 은 **객관적으로 증명하기 어려운 최상급 표현**이라, 의료광고 심의에서
문제가 될 소지가 있습니다. 제가 임의로 고치지 않고 그대로 두었습니다.

번역본(영어·중국어·일본어·러시아어)에서는 "줄기세포 의학에 기반한" 정도로
낮춰 두었습니다. **한국어 원문도 한 번 검토해 주십시오.**

→ **판단:** (그대로 / 수정 — 수정 문안:)

그 자체로 과장 광고**가 되므로, 아래 문장들이 네 언어 모두에 남아 있는지
우선 확인해 주십시오. (제가 넣어 두었지만, 의료진 검수가 필요합니다.)

## ④ 사진 — 병원에서 주셔야 하는 것

### - [ ] 12. 병원 실제 사진 6장

갤러리에 자리 6칸이 **비어 있습니다.**

| 자리 | 필요한 사진 |
|---|---|
| 1 | 병원 전경 |
| 2 | 접수 · 대기 공간 |
| 3 | 진료실 |
| 4 | 시술실 |
| 5 | 에스테틱 케어룸 |
| 6 | 회복실 |

가로세로 4:3, 긴 변 1600px 정도면 충분합니다.
사진을 넣으면 **누르면 크게 보이는 기능이 자동으로 켜집니다.**

> ⚠ **무료 스톡 사진이나 AI 그림으로 채우지 않았습니다.**
> 실제와 다른 시설 사진은 의료법상 거짓·과장 광고에 해당할 수 있고,
> 그 사진을 보고 오신 분이 다른 공간을 마주하게 됩니다.
> 그래서 분위기용 그림(`images/motif-*.svg`)은 따로 만들어 쓰고,
> **갤러리는 진짜 사진이 올 때까지 비워 두었습니다.**

## ⑤ 보안 · 운영 — 병원(또는 담당자)이 처리하셔야 하는 것

### - [ ] 14. 카페24 FTP 비밀번호 변경 ⚠ 보안

FTP 접속 정보가 **메신저로 평문 전달된 이력**이 있습니다.
대화방에 남아 있는 한 계속 노출 상태입니다.

- 서버: `namsun01.mycafe24.com`
- 아이디: `namsun01`

→ **[ ] 비밀번호 변경 완료** (변경 후 새 비밀번호는 메신저로 보내지 마십시오)

### - [ ] 15. mdmiraecell.com 연결

현재 `mdmiraecell.com` 에는 **카페24 초기 홈페이지**가 걸려 있습니다.
새 홈페이지는 임시 주소에서만 보입니다.

→ 임시 주소: https://intoedu.github.io/mdmiraecell/

카페24에 올리려면 **FTP 정보 4개를 GitHub 시크릿에 등록**해야 합니다.
(`CAFE24_FTP_HOST` / `USER` / `PASSWORD` / `DIR`)
올리기 전에 **기존 `/www` 폴더를 통째로 백업**해 두십시오.

→ **[ ] 백업 완료** / **[ ] 시크릿 등록 완료** / **[ ] 배포 완료**

### - [ ] 16. 알림 메일이 스팸함으로 갑니다

새 예약·문의가 들어오면 `mdmiraecellclinic@gmail.com` 으로 알림이 갑니다.
지금은 **Gmail이 스팸으로 분류**하고 있어, 필터로 임시 조치만 해 둔 상태입니다.

근본 해결은 **Resend에서 도메인 인증(mdmiraecell.com)** 입니다.
도메인 DNS에 값 몇 개를 추가하면 됩니다. 카페24 DNS 관리 화면에서 하실 수 있습니다.

→ **[ ] Resend 도메인 인증 완료**

## 확인되면 어떻게 전달하시면 되나요

한 번에 다 모으지 않으셔도 됩니다. **확인되는 것부터 하나씩** 알려 주시면
그때그때 반영해 올리겠습니다.

간단한 것(주소, 진료시간, 성함 표기, SNS 주소)은 알려 주시는 즉시 반영됩니다.
사진은 파일을 주시면 됩니다.
