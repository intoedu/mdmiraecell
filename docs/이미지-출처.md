# 이미지 출처 기록표

홈페이지에 올린 모든 사진과 그림의 출처를 여기에 적습니다.
저작권 문의나 분쟁이 생겼을 때 이 표와 캡처 파일이 증빙이 됩니다.

선정 기준과 라이선스 조건은 `docs/무료이미지-가이드.md` 를 보십시오.

---

## ① 병원 실제 사진 (`images/clinic/`)

병원에서 직접 촬영해 주신 사진입니다. 저작권은 병원에 있습니다.

| 파일명 | 사용 페이지 | 무엇을 찍은 사진인지 | 받은 날 | 반영한 날 | 사람 나옴 | 동의서 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

> 사람이 찍힌 사진은 **본인 서면 동의서를 받아 두신 경우에만** 올립니다.
> 동의서는 이 저장소가 아니라 병원에서 따로 보관하십시오.

---

## ② 무료 스톡 이미지 (`images/stock/`)

| 파일명 | 사용 페이지 | 출처 | 콘텐츠 번호 / 주소 | 받은 날 | 반영한 날 | 라이선스 캡처 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

> **클립아트코리아 무료콘텐츠는 받은 날로부터 30일 안에 반영해야 합니다.**
> 기한이 지난 것은 다시 받아서 "받은 날"을 새로 적습니다.

---

## ③ 기존 이미지 (출처 확인 필요)

홈페이지 제작 초기부터 있던 파일입니다. 출처가 기록되어 있지 않습니다.

| 파일명 | 사용 위치 | 출처 |
|---|---|---|
| `images/logo.svg` · `images/명동미래셀의원 로고.svg` | 머리글 · 바닥글 | 병원 제공 (제작처 확인 필요) |
| `images/favicon.svg` · `images/명동미래셀의원 파비콘.svg` | 브라우저 탭 | 병원 제공 (제작처 확인 필요) |
| `images/og.png` · `images/명동미래셀의원 OG.png` | 카카오톡 · SNS 공유 미리보기 | 병원 제공 (제작처 확인 필요) |
| `images/doctor.jpg` · `images/박종윤 원장.png` | 의원 소개 | 병원 제공 — 원장님 사진 |
| `images/motif-*.svg` (5개) | 진료과목 페이지 배경 | 이 홈페이지 작업 중 직접 그린 벡터 그림 (외부 출처 없음) |

> 로고·파비콘·OG 이미지를 외부 디자이너가 만들었다면,
> **작업물의 저작재산권이 병원에 양도되었는지** 확인해 두시는 편이 좋습니다.
> 계약서에 양도 조항이 없으면 저작권은 만든 쪽에 남아 있는 것이 원칙입니다.
