**Pixabay 라이선스 요약** (가이드 확인일 2026-09-17)

- 상업적 사용 가능, **출처 표기 의무 없음**
- **사용 기한 없음** — 클립아트코리아의 30일 규칙은 해당하지 않습니다
- 다만 사진 속 인물 · 로고 · 브랜드 · 건물에는 별도 권리가 있을 수 있고,
  제3자 동의가 필요한지 판단할 책임은 **쓰는 쪽**에 있습니다

### ⚠ Editorial Use Only 확인이 필요합니다

Kaboompics 는 사진마다 **`Editorial Use Only`** 표시가 붙을 수 있습니다.
그 표시가 있으면 알아볼 수 있는 **상표 · 로고 · 작품 · 건물 · 인물**이 담겨 있어
**상업적 사용 허가가 나지 않은 사진**입니다. 병원 홈페이지는 상업적 사용입니다.

받으신 다섯 장에 그 표시가 있었는지 확인이 필요하고,
특히 **`kb-contact-desk.jpg`** 는 사람이 나오므로 우선 확인해 주십시오.

→ 다섯 장 모두 표시 없음: **[ ]**  /  표시 있는 사진 있음: **[ ] 파일명 __________**

**인물이 나오는 사진 1장** — `kb-contact-desk.jpg` 에 창가에서 노트북을 보는
사람이 뒷모습으로 나옵니다. 얼굴은 보이지 않고, 문의하기 페이지라 진료·시술
페이지가 아닙니다. 화면 속 글씨도 확대해 확인했고 읽히는 상표는 없습니다.
다만 위 Editorial Use Only 확인이 끝나기 전까지는 미결로 둡니다.

**밝기를 손본 사진 2장** — `stemcell-bubbles` 와 `px-lymph-palm` 은 원본이 밝아
띠 위의 흰 글씨가 묻혔습니다. 감마 곡선으로 눌러서 넣었습니다.
`worldtour-palm` 과 `quantum-fronds` 는 반대로 너무 어두워 끌어올렸습니다.

> **클립아트코리아 무료콘텐츠는 받은 날로부터 30일 안에 반영해야 합니다.**
