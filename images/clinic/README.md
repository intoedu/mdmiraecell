# images/clinic — 병원에서 직접 찍은 실제 사진만

이 폴더에는 **명동미래셀의원에서 실제로 촬영한 사진**만 넣습니다.

갤러리와 의원 소개에서 "우리 병원의 공간"으로 소개되는 사진이므로,
여기 들어온 파일은 전부 실물과 일치해야 합니다.

## 넣으면 안 되는 것

- 무료 스톡 사진 (클립아트코리아 · Pixabay 등) → `images/stock/`
- AI로 만든 그림 → `images/stock/`
- 다른 병원 · 다른 지점 사진

실제와 다른 시설 사진은 의료법상 거짓·과장 광고에 해당할 수 있습니다.
사진을 보고 찾아오신 분이 다른 공간을 마주하게 되는 문제도 있습니다.

## 파일 이름

용도를 알아볼 수 있게 영문 소문자와 하이픈으로 적습니다.

```
exterior-01.jpg      병원 전경
reception-01.jpg     접수 · 대기 공간
consult-01.jpg       진료실
procedure-01.jpg     시술실
esthetic-01.jpg      에스테틱 케어룸
recovery-01.jpg      회복실
```

## 규격

- 가로 사진, 가로세로 4:3
- 긴 변 1600px (갤러리 표시 칸은 365×274px, 고해상도 화면까지 감안한 크기)
- JPEG, 장당 300KB 안쪽
- **촬영 위치·기기 정보(EXIF)는 지우고 올립니다**

원본은 규격에 맞추지 않은 채로 주셔도 됩니다. 위 작업은 반영하면서 진행합니다.

## 사람이 찍힌 사진

환자분·직원분 얼굴이 들어간 사진은 **본인 서면 동의 없이 올리지 않습니다.**
동의를 받기 어려우면 사람이 없는 시간대에 다시 찍는 편이 빠릅니다.
