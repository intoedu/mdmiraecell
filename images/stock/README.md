# images/stock — 무료 스톡 이미지 (분위기 · 개념 컷)

클립아트코리아 무료콘텐츠, Pixabay 등에서 받은 이미지를 넣습니다.
선정 기준과 라이선스 조건은 `docs/무료이미지-가이드.md` 를 따릅니다.

## 절대 규칙

**스톡 이미지를 "우리 병원의 진료실 · 시술실 · 대기실"로 소개하지 않습니다.**

쓸 수 있는 자리는 분위기를 만드는 배경과 개념을 설명하는 그림까지입니다.

| 쓸 수 있음 | 쓸 수 없음 |
|---|---|
| 진료과목 페이지의 배경 · 표지 이미지 | 갤러리 (`gallery.html`) |
| 세포 · 해부도 같은 개념 설명 그림 | "저희 병원 ○○실" 이라는 설명이 붙는 자리 |
| 잎 · 빛 같은 추상 배경 | 원장님 · 직원 사진 자리 |

갤러리는 실제 사진이 올 때까지 비워 둡니다.

## 사람이 나오는 사진

**진료 · 시술 관련 페이지에는 인물 사진을 쓰지 않습니다.**
모델이 시술 효과를 보증하는 것처럼 읽힐 수 있어 초상권과 의료법 양쪽에서 문제가 됩니다.
특히 비뇨의학 페이지는 "이 사람이 그 질환이 있다"는 인상을 줄 수 있어 위험이 가장 큽니다.

## 파일 이름

출처를 아는 경우 `출처-용도-번호` 순서로 적어, 파일 이름만으로 구분되게 합니다.

```
ck-leaf-bg-01.jpg        클립아트코리아 (ck)
px-stemcell-3d-01.jpg    Pixabay (px)
kb-scalp-mint.jpg        Kaboompics (kb)
```

출처를 아직 모르면 **쓰이는 자리로 이름을 붙이고**, `docs/이미지-출처.md` 의
출처 칸을 비워 둔 채 `확인 필요` 로 남깁니다. 지어내서 채우지 않습니다.

```
hero-leaves.jpg          홈 히어로 배경
reserve-desk.jpg         예약 페이지 상단 띠
```

## 출처별로 다른 점

| | 상업적 사용 | 출처 표기 | 사용 기한 | 특히 볼 것 |
|---|---|---|---|---|
| Pixabay | 가능 | 불필요 | 없음 | 인물·상표·건물의 별도 권리는 보장 안 됨 |
| Kaboompics | 가능 | 불필요 | 없음 | **Editorial Use Only 표시** — 있으면 상업적 사용 불가 |
| 클립아트코리아 | 가능 | 불필요 | **30일** | 인물 콘텐츠는 의료뷰티 카테고리만 |

**Kaboompics 는 사진마다 `Editorial Use Only` 가 붙을 수 있습니다.**
그 표시가 있으면 알아볼 수 있는 상표·로고·작품·건물·인물이 담겨 있어
상업적 사용 허가가 나지 않은 사진입니다. 병원 홈페이지는 상업적 사용이므로
**받기 전에 그 사진 페이지에서 표시를 확인해야 합니다.**

어느 출처든 공통으로 금지되는 것

- 사진 자체를 다시 팔거나 스톡 이미지로 재배포하는 것
- 오해를 부르거나 명예를 훼손하는 방식으로 쓰는 것

## 받은 뒤 반드시

`docs/이미지-출처.md` 기록표에 **한 줄 추가하고** 라이선스 페이지를 캡처해 둡니다.
분쟁이 생겼을 때 "무료였다"는 말만으로는 증빙이 되지 않습니다.
